# Frontend contribution instructions

This checkout is standalone and is not currently connected to Lovable Git sync.

If this repository is connected to Lovable later, preserve the original integration instructions:

- Avoid rewriting published Git history: do not force push or rebase, amend, or squash commits that are already pushed. Rewriting connected history can lose the project's history in Lovable.
- Keep the connected branch in a working state. Commits pushed to that branch synchronize back to the Lovable editor only after Git sync has been configured.
